# OD-06 — Meta ad data access tier

**Status:** OPEN — Tier 3 (manual intake) ships as the baseline
**Owner:** Engineering
**Needed by:** Phase 0 (blocking)
**Blocks:** MI-01…MI-05 (Meta Ads Intelligence)

## Question

Which tier of Meta ad data can we actually obtain for Bangladesh commercial advertisers?

## Why it matters

This decision can invalidate an entire feature. If no tier returns usable data for
Bangladesh commercial ads, Meta Ads Intelligence does not ship in its intended form.

## Options considered

| Tier | Source | Coverage for BD commercial ads | Effort | Freshness |
|---|---|---|---|---|
| 1 | Official Meta Ad Library API | unverified — the API's country/type coverage is the question | medium | live |
| 2 | Licensed provider | depends on the provider's own collection | low | varies |
| 3 | Manual intake (CSV upload by staff) | complete — the business supplies its own data | low | per-upload |

## Applied default

**Tier 3 ships as the baseline.** The ads intelligence module is built against an
`AdSource` interface with a `source_tier` on every snapshot, so tier 1 and tier 2 are
additive later without changing anything above them.

The rule from MI-03 is enforced in the model: **metrics from different tiers are never
mixed into one ranking.** A Tier-3 snapshot and a Tier-1 snapshot cannot be compared
directly, because they are not the same measurement.

MI ships in reduced form with an honest coverage banner when only tier 3 is available.

## Investigation still required

1. Test the official Ad Library API for the target country and ad type. Does it return
   commercial advertisers, or only political ads? What is the actual response shape?
2. Check a licensed provider's BD coverage. Is the coverage complete enough to rank?
3. Confirm the business is willing to upload data manually, and at what cadence.
