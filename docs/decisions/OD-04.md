# OD-04 — Bubble persistence and dismissal rules

**Status:** APPLIED (default)
**Owner:** Product + Design
**Needed by:** Phase 2
**Blocks:** CG-08, CG-11

## Question

Are bubbles in-dashboard only, and what happens when a dismissed customer messages again?

## Applied answer

- Bubbles live **in the dashboard only**. Nothing is pushed to the customer's channel
  as a bubble (CG-11 — the dashboard is where staff work).
- Bubbles are **persisted indefinitely**. There is no expiry, because the underlying
  insight (this customer is a returning buyer) does not expire.
- A dismissed bubble **re-opens** on a new inbound message from that customer in that
  conversation. Staff dismissed it once; new information means it deserves a second
  look.
- The state machine is `new → seen → dismissed`, with `dismissed → new` on a new
  inbound message.

## Options considered

| Rule | Pro | Con |
|---|---|---|
| A. Persist, re-open on new message | staff never miss a live conversation | an old bubble can resurface |
| B. Persist, never re-open | simple | staff miss a returning customer who messages again |
| C. Expire after N days | dashboard stays clean | loses the returning-customer signal entirely |

Chosen A. The state machine lives in `customer_bubbles.state`.
